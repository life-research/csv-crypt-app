# Security Policy

## Supported Versions

Only the latest release receives security fixes. Please update to the
latest release before you report a vulnerability.

| Version        | Supported |
| -------------- | --------- |
| Latest release | ✅        |
| Older releases | ❌        |

## Reporting a Vulnerability

Do not report vulnerabilities in public issues, pull requests or
discussions.

Report them privately through GitHub:

1. Open the [Security tab](https://github.com/life-research/csv-crypt-app/security)
   of this repository.
2. Click **Report a vulnerability**.
3. Fill in the form.

Please include:

- The affected version and build (web app, single file or desktop app).
- The browser or operating system.
- The steps to reproduce the problem.
- The possible impact, for example data that an attacker can read.

## What Happens Next

- You receive a first answer within 7 days.
- We confirm the problem and work on a fix.
- We publish the fix and a security advisory. We credit you in the
  advisory, unless you do not want this.

Please do not disclose the vulnerability before we publish the fix.

## Scope

This policy covers this repository: the web app, the single file build
and the desktop app. Report vulnerabilities in the command line tool to
[csv-crypt](https://github.com/life-research/csv-crypt).
